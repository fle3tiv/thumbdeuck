ThumbDEuck 1._
A small desktop made from scratch in Python.

Succesfully developed by a 12 year old.
If you are reading this then you are probably one of my friends as this is a prototype version as it end with . _

-Funcntionality
Needs: Arch Linux with a working Xorg login screen.

Install:
  tar xzf thumbdeuck.tar.gz
  cd thumbdeuck-release
  ./install.sh

Then log out, pick "ThumbDEuck" in the session menu, and log in.

Keys: Super+Enter = terminal, Super+Q = close, Super+Up = maximise,
Super+Tab = bring back a minimised window, Super+drag = move/resize.
Power menu (log out, restart, shut down): open the menu, click Power.

Your old desktop stays installed, so you can always pick it instead.
The installer backs up any picom/alacritty/fastfetch config you had.
